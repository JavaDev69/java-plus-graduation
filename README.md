# Проект ExploreWithMe — афиша событий 


Позволяет пользователям делиться информацией об интересных событиях и находить компанию для участия в них.

---
## Модули проекта

### Функциональные

| Сервис                 | Описание                                                      | Порт по умолчанию |
|------------------------|---------------------------------------------------------------|:-----------------:|
| `stats-server`         | сервис для работы со статистикой посещений                    |       9090        |
| `category-service`     | сервис для работы с категориями                               |       9291        |
| `user-service`         | сервис для работы с пользователями                            |       9292        |
| `event-service`        | сервис для работы с событиями                                 |       9293        |
| `request-service`      | сервис для работы с запросами на участие в событиях           |       9294        |
| `compilation-service`  | сервис для работы с подборками событий                        |       9295        |
| `comment-service`      | сервис для работы с комментариями к событиям                  |       9296        |
| `subscription-service` | сервис для работы с подписками пользователей на пользователей |       9297        |
| `rating-service`       | сервис для работы с рейтингом событий                         |       9298        |

>[!NOTE]
>Порт по умолчанию используется при запуске вне Docker, при запуске в Docker приложения запускаются на произвольном свободном порту

### Инфраструктурные

| Сервис             | Описание                                                                                        | Порт по умолчанию |
|--------------------|-------------------------------------------------------------------------------------------------|:-----------------:|
| `config-server`    | Централизованный сервер для управления внешними конфигурациями микросервисов                    |         -         |
| `discovery-server` | Централизованный реестр (сервер имен), где микросервисы регистрируют <br>свои IP-адреса и порты |       8761        |
| `gateway-server`   | API Gateway - единая точка входа                                                                |       8080        |
